# Luna_Apparel
Luna Apparel – a fashion website showcasing clothing products and information about the brand.
Luna Apparel

Project Overview

Luna Apparel is a fashion website designed to showcase clothing products in a simple, attractive and user-friendly way. The website provides visitors with information about the brand and allows them to browse the available products.

Goals

The main goals of the Luna Apparel website are to:

- Create a professional-looking fashion website.
- Provide clear information about Luna Apparel.
- Display clothing products with images and descriptions.
- Make the website easy to navigate.
- Practise HTML and web-development skills.
- Create a responsive and organised website structure.

Sitemap

Planned Features

- Home page with a welcome section.
- About page containing information about Luna Apparel.
- Products page displaying clothing items.
- Navigation links between pages.
- Product images and descriptions.
- Clear headings and organised sections.
- Simple and consistent visual design.
