# Luna_Apparel


A fashion website showcasing clothing products and information about the brand.

Project Overview

Luna Apparel is a fashion website designed to showcase clothing products in a simple, attractive and user-friendly way. The website provides visitors with information about the brand and allows them to browse the available products.

For Part 2, CSS styling and responsive design were added to improve the appearance, layout and usability of the website across different screen sizes and so on.

Goals

The main goals of the Luna Apparel website are to:

- Create a professional-looking fashion website.
- Provide clear information about Luna Apparel.
- Display clothing products with images, descriptions and prices.
- Make the website easy to navigate.
- Practise HTML and web development skills.
- Use CSS to create a consistent visual design.
- Use responsive design so the website can adjust to different screen sizes.
- Create an organised and user-friendly website structure.

Part 2 Features

CSS Styling

CSS was added to improve the overall appearance of the website. This includes:

- Typography and font styling
- Font sizes and weights
- Colours and backgrounds
- Spacing and alignment
- Borders and rounded corners
- Product card styling
- Buttons and links
- Hover, focus and active effects
- Form styling
- Consistent styling across all pages

Layout

CSS Flexbox and/or Grid were used to organise content and create structured layouts for the website.

Responsive Design

The website was made responsive so that the content can adjust to different screen sizes, including:

- Desktop
- Tablet
- Mobile

Media queries and responsive units were used to help the website adapt to different screen widths.

Product Section

The Products page displays clothing and accessories with:

- Product images
- Product names
- Product descriptions
- Prices
- Organised product sections/categories

Testing

The website was tested using Visual Studio Code and Live Preview.

Different browser window sizes were used to check that:

- Navigation works correctly.
- Images display correctly.
- Pages are linked correctly.
- Content remains organised.
- The layout adjusts to different screen sizes.
- The website remains readable on smaller screens.
- Forms and other styled elements display correctly.
